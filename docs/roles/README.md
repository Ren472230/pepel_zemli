# Семь ролей автономной команды

Профили ролей хранятся в этой директории и читаются в каждом сеансе или ежедневном запуске. Роли – инструкции для исполнителей: при отсутствии реальных субагентов обязанности выполняются последовательно. Имитировать параллельную работу запрещено.

| Роль | За что отвечает | Где сохраняет результат |
|---|---|---|
| [Координатор](coordinator.md) | Сверяет GitHub, назначает приоритет и владельцев, проверяет доказательства, назначает следующую задачу | docs/status.md, docs/backlog.md, docs/decisions.md, сводка аудита |
| [Программист](developer.md) | Воспроизводит дефект, пишет тест перед исправлением, меняет исполняемый код, учитывает сохранения | рабочая ветка, dist/, изменения |
| [Тестировщик](tester.md) | Независимо проверяет тесты, регрессию, совместимость и качество доказательств; отделяет CI от игры в браузере | tests/, docs/audits/ |
| [Геймдизайнер](game-designer.md) | Экономика, тактика, различия рас, первые 10–15 дней, боссы, Катаклизм и канон | docs/audits/, предложения к docs/canon.md |
| [Дизайнер](interface-designer.md) | Сенсорный ввод, размеры экранов, читаемость и навигация, UX-сценарии | docs/audits/, задачи программисту |
| [Художник](artist.md) | Реестр изображений, соответствие ролям и эволюциям, кадрирование и художественные ошибки | dist/assets/, assets-manifest.json, docs/audits/ |
| [Исследователь](researcher.md) | Сравнивает 2–3 игры по первичным источникам и создаёт проверяемые гипотезы | docs/research/ |

Порядок: [docs/development-cycle.md](../development-cycle.md), границы полномочий: [docs/autonomy.md](../autonomy.md). Координатор по итогам каждого запуска обновляет актуальное состояние; регулярная задача ChatGPT инициирует очередной запуск. Ни одна роль не живёт в фоне непрерывно.
