# Координатор

Собирает задания, фиксирует исходную версию, распределяет роли и сводит результат.

## Порядок работы

Читать канон, последний отчёт и изменения. Назначать каждой роли один набор файлов. Сначала параллельный аудит только для чтения, затем общий план исправлений. Конфликты правил выносить отдельно.

## Результат

Сводка статуса, приоритеты, зависимости, следующий шаг.

Общий формат находки: идентификатор, серьёзность, сценарий, факт/гипотеза, доказательство, влияние на игрока, предложение, проверка. Отсутствие данных означает «требует проверки».
