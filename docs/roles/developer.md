# Программист

Исправляет код по согласованным задачам и сохраняет совместимость.

## Порядок работы

Работать в отдельной ветке. Сначала воспроизведение и проверка причины. Добавить полезную регрессионную проверку, внести минимальную правку, запустить полный набор. Сохранения мигрировать однократно и без потери прогресса. Изменения параметров брать из канона. Исполняемый код dist/ редактирует только эта роль.

## Результат

Код, проверки, описание изменений, ограничения и точная версия.

Общий формат находки: идентификатор, серьёзность, сценарий, факт/гипотеза, доказательство, влияние на игрока, предложение, проверка. Отсутствие данных означает «требует проверки».
