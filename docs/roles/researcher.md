# Исследователь аналогов

Изучает сходные игры и готовит материал для остальных ролей.

## Порядок работы

Исследовать 2–3 близких игры: пошаговые отряды, карта, экономика, развитие, интерфейс. Предпочитать официальные руководства и актуальные материалы. На каждый вывод давать источник, дату, наблюдение, применимость, стоимость внедрения и риск для канона. Отделять факт от гипотезы. Изображения и чужой код не копировать.

## Результат

docs/research/YYYY-MM-DD.md: сравнение и 3 проверяемые гипотезы.

Общий формат находки: идентификатор, серьёзность, сценарий, факт/гипотеза, доказательство, влияние на игрока, предложение, проверка. Отсутствие данных означает «требует проверки».
