# Очередь автономной разработки

Актуально на 17.10.2026. Режиссёр принимает решение о продуктовых приоритетах и результате работы по docs/product-roadmap.md; координатор обновляет файл после каждого цикла. Приоритет: P0 – невозможно играть или теряется прогресс; P1 – мешает основному сценарию; P2 – снижает удобство; P3 – гипотеза улучшения. Статусы: ожидает, в работе, проверено, заблокировано.

| Код | Приоритет | Статус | Владелец | Задача | Критерий готовности |
|---|---|---|---|---|---|
| UI-001 | P2 | код проверен, UX ожидает | дизайнер + программист + тестировщик | Карта 8×8 на узком телефоне: клетки потенциально меньше 44 px; обеспечить доступное касание и горизонтальную прокрутку при необходимости | Каждая доступная клетка >=44×44 CSS px, карта доступна на 360/390 px, регрессия + браузерная проверка при наличии |
| QA-001 | P1 | заблокировано авторизацией Sites | тестировщик + координатор | Проверить опубликованную версию против main | Сравнение точных версий GitHub и Sites, доступ владельца сохранён |
| GAME-001 | P1 | следующий автономный приоритет | геймдизайнер + тестировщик | 10–15 игровых дней за четыре расы с экономикой и рандомом | Четыре воспроизводимых сценария, запись смертей, запасов, потерь и безвыходных состояний |
| COMBAT-001 | P1 | код принят по CI 17.10; требуется игровое прохождение | программист + геймдизайнер | Нейтральные существа наследуют параметры базового бойца вместо собственного боевого профиля | Характеристики каждого вида определены и покрыты тестами, канон и сохранения согласованы |
| EVOL-001 | P2 | ожидает решения о каноне | геймдизайнер + художник | 84 формы есть, но четыре корневых ветви имеют 1/3 потомка вместо 2/2 | Утверждена раскладка ролей и портретов с сохранением 84 форм и прогресса |
| UX-002 | P2 | ожидает | дизайнер интерфейса | Читаемость боёв и перекрытие действий на 360/390/768/1366 px и масштабе 200% | Снимки карты, боя, модального окна, экипировки; список конкретных препятствий |
| GAME-002 | P2 | ожидает | геймдизайнер + программист | Формула опыта за жертву, условия демонического поручения и обновление поселений расходятся с формулировками канона | Зафиксировано решение владельца или выявлена точная совместимая правка |
| ASSET-001 | P2 | ожидает | художник | Визуальная сверка 115 изображений, кадрирование маленьких плиток и соответствие ролям | Таблица соответствий, примеры снимков экрана, список только реальных ошибок |
| RELEASE-001 | P1 | запланировано, требует проверки доступа к Sites | режиссёр + координатор + тестировщик | Безопасный воскресный выпуск подтверждённой версии в живой сайт | Work/Sites доступны, проверены код, аудитория владельца, точный коммит и реальная опубликованная версия; иначе честная блокировка |
| FEEL-001 | P2 | нужны реальные наблюдения | режиссёр + геймдизайнер + дизайнер | Проверить, насколько первые 10–15 дней интересны и понятны игроку | Наблюдения реального прохождения, конкретные проблемы и небольшие измеримые предложения |
| RESEARCH-001 | P3 | проверено исследованием | исследователь + геймдизайнер | Сравнить подход к ранним целям и решениям в Battle Brothers, Wartales, Wesnoth | Ссылки на первичные источники, 3 гипотезы, стоимость и риск |
| PLATFORM-001 | P1 | проверено в GitHub Actions | координатор + программист | Настроить автоматические тесты в GitHub и однозначное состояние выпуска | CI запускается в ветках/PR; есть подтверждённый результат тестов; релиз отдельно |

## Очередность

Решение режиссёра от **17.10.2026**: **COMBAT-001** прошёл техническую приёмку на коммите [80248e7](https://github.com/Ren472230/pepel_zemli/commit/80248e76c1281d6a6ae709eefb209df43721940d), [успешный CI](https://github.com/Ren472230/pepel_zemli/actions/runs/39004463474), [отчёт цикла №2](audits/2026-10-17-cycle-02.md). Для новых нейтралов ещё необходима игровая приёмка реальных встреч. **Следующий основной P1 – GAME-001:** первые 10–15 дней за четыре расы с ресурсами, случайными картами и развилками после поражений. При появлении игрового браузера вернуться к QA-001, UX-002 и UI-001. EVOL-001 и GAME-002 остаются под защитой канона; RELEASE-001 ведёт отдельный воскресный процесс. Ежедневный цикл ничего не публикует в Sites.
