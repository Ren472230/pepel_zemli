## Конкретная устранённая причина

Карта 8×8 на телефоне помещала восемь колонок в узкий контейнер без гарантированного минимального размера клетки. Добавлено ограничение ширины колонок и кнопок 44px, разрешена горизонтальная прокрутка. Новый тест tests/mobile-map.cjs падал на исходной версии из-за отсутствующего минимального размера: GitHub Actions №38707800224. После CSS-правки GitHub Actions №38707946999 завершился успешно, включая npm test и npm run audit. Эти проверки подтверждают свойства CSS и сохранность существующих игровых тестов; визуальные сценарии должны выполняться отдельно.

## Другие выявленные несоответствия

- EVOL-001: в 84 формах две корневые ветви имеют одного потомка, две – трёх; симметрия 2×2 нарушена, есть запись в docs/audit-v8.md. Нельзя перепривязывать дерево без согласования канона и миграции сохранений.
- COMBAT-001: функции нейтралов в исходном коде опираются на базового воина (см. docs/canon.md, §9); исследовать характеристики каждого вида.
- QA-001: внешняя проверка живого Sites остановлена на экране «Log in to access», значит игровое содержимое реально не проверено.

## Релиз

На момент формирования отчёта изменения находятся в ветке GitHub. Публикация живого Sites этим запуском не выполнена. Репозиторий остаётся публичным с прежними правами. Задача автозапуска ChatGPT создана отдельно.
