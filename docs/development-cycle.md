# Цикл по команде «запускай»

1. Координатор читает текущую версию репозитория и канон, создаёт каталог docs/audits/<дата-время>/ и фиксирует исходный коммит. Изменения текущей живой версии сверяются с журналом выпуска.
2. Программист запускает `npm test` и `npm run audit`, фиксирует технические риски. Тестировщик отдельно проверяет достоверность доказательств.
3. Исследователь собирает свежие первичные источники по 2–3 аналогам. Остальные роли могут начать проверку существующей игры параллельно, затем учитывают его выводы при предложении решений.
4. Геймдизайнер проверяет первые 10–15 дней каждой расы, потери, провизию, золото, полезность добычи, выборы развития; отдельно босса и Катаклизм. Отсутствие настоящего прохождения указывается явно.
5. Дизайнер проверяет мобильные и компьютерные сценарии, художник соответствия и кадрирование. При отсутствии подходящего инструмента браузерные проверки отмечаются незавершёнными.
6. Координатор собирает находки, убирает дубликаты, отмечает противоречия канону. Критичность: блокирует игру; мешает основному сценарию; снижает удобство; идея улучшения.
7. Сводка выводится в чате интерактивной панелью: роль, состояние, подтверждённые проблемы, доказательства, следующий шаг. Также сохраняются JSON и HTML отчёты. Факты и гипотезы разделены; неизвестное не окрашивается как успешное.
8. Результат аудита: что проверено, что мешает играть, что пока неизвестно, три главных следующих задачи. Отдельный вопрос игроку: было ли интересно, где стало скучно или несправедливо. Его ответ становится доказательством игрового опыта.
9. После указания исправлять программист реализует задачи в ветке, независимый тестировщик перепроверяет. Канон обновляется вместе с кодом. Публикация по docs/release.md, затем проверка результата и новый отчёт.

## Статусы направления

«Подтверждено проверкой», «Обнаружена проблема», «Гипотеза», «Требует проверки», «Заблокировано». Для каждой отметки обязательны источник, версия, дата и ограничения. Отдельные направления: код, первые дни, экономика, способности, интерфейс телефона, интерфейс компьютера, изображения, удовольствие от игры.

## Передача между чатами

Достаточно ссылки на репозиторий и команды «Прочитай AGENTS.md и запускай». Историю чата использовать как уточнение. Если канон противоречит новой прямой инструкции пользователя, обновить решение в журнале, сохранив причину изменения.
