# Работа над «Пепельными землями»

Главный репозиторий: https://github.com/Ren472230/pepel_zemli . Перед работой прочитать README.md, docs/canon.md, docs/development-cycle.md и профиль роли в docs/roles/.

## Команда «запускай»

Означает запуск аудита текущей версии по docs/development-cycle.md. Координатор вызывает независимых исполнителей семи ролей, если среда поддерживает делегирование. При отсутствии делегирования выполняет роли последовательно и явно отмечает это. Никаких выдуманных параллельных агентов или фоновой работы. Роли существуют как инструкции проекта; запуск обеспечивается текущим ИИ-сеансом.

Проверки разрешены при команде «запускай». Исправления воспроизводимых ошибок в пределах канона выполнять после отдельного указания «исправляй» или «накатывай». Изменение канона, новые большие механики и перенос сайта на другой сервис оформлять предложением пользователю. Команда «запускай» сама по себе запускает аудит, без автоматической публикации игровых изменений. Явное «исправляй/накатывай» разрешает реализацию и публикацию проверенной версии.

## Разделение работы

Аудит выполняется только для чтения. На этапе исправлений один исполнитель владеет dist/index.html, dist/expansion.js и dist/expansion.css. Художник владеет назначенными изображениями, геймдизайнер каноном, тестировщик тестами. Перед записью общий план и список владельцев. Использовать отдельные ветки или рабочие копии, сверять актуальную исходную версию перед объединением. Не перезаписывать чужие изменения.

## Доказательства

Указывать версию и дату. Автоматические тесты с моделью документа не являются проверкой в настоящем браузере. Работоспособность кода, удобство интерфейса, баланс и удовольствие от игры имеют отдельные статусы. Проценты готовности без методики запрещены. Оценки игрока не выдумывать.

## Исходники и выпуск

GitHub – источник кода и канона. dist/ содержит игру, tests/ и test-*.cjs проверки. Не добавлять сохранения пользователей, токены, личные данные, архивы развёртывания. Публикация Sites выполняется отдельно по docs/release.md; наличие коммита в GitHub само по себе сайт не обновляет. Перед выпуском npm test и сверка assets-manifest.json.
